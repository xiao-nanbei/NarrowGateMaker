这是待核查地图，不是所有消费者量纲正确的认证。已完成经济结果属于冻结执行实现；以后若确认缺陷，应评估影响并另立纠正身份，不修改旧回执，不对已打开的 Final 调参追求盈利。

| 数量 | 必须区分的单位或语义 | 审查边界 |
| --- | --- | --- |
| 价格／绝对距离 | USDC/BTC，不是 tick、bps 或相对收益 | P3 校准 → 标签 → 报价距离 |
| 仓位／成交量 | BTC，不是报价币名义金额或成交笔数 | 解析 → 成交 → 现金和库存 |
| 方差率 | (USDC/BTC)²/秒，不是标准差或无量纲收益方差 | 标签及模型元数据 → 波动预测 → 报价风险 |
| 方向／毒性 | 概率或明确定义的分数，不是货币金额 | 各 head 标签 → 推理 → 动作映射 |
| 收益预测 | 查明触达条件目标及归一化，不能从变量名猜单位 | 标签生成 → 回放桥接 → live 信号 |
| 手续费／资金费 | 无量纲费率与带符号 USDC 现金流，支付／收取符号及名义本金 | 成交和资金费输入 → 账本 |
| 时间 | CSV 微秒、内部纳秒、API 毫秒、horizon 秒、半衰期 UTC 日 | 解析 → 观察 → 标签 → 资金费边界 |
| 计数 | 个体成交、聚合消息、不可得原生包数不同 | 来源适配 → 滚动窗口 → 模型特征 |
| 期末价值 | BTC 库存 × USDC/BTC 估值，不是假定免费平仓 | 分片权益 → 日账 → 汇总 |

从[新输入标签](public_input_panel.py)、[模型校验](../../../strategy/public_model_contract.py)、[方差合同](../../../strategy/model_contract.py)、[live 协议](../../../live/feature_protocol.py)、[观察时钟](../../../data/observation.py)、[经济会计](../../../models/replay/public_accounting.py)及实际调用者开始核查；本族到仓库根目录使用三级父路径。

建议测试价格乘十／数量除十的名义金额不变关系，秒／毫秒／微秒／纳秒非零偏移换算，bps↔小数↔绝对价格，资金费支付收取符号和精确边界，未知与观测零，成交聚合后的计数差异，以及方差和标准差转换。缩放是变形测试，不授权修改 tick/lot 限制或冻结数据。
