# F05 Formal-v25 Semantic Resume Failure

Last materially modified: 2026-08-18

Status: `failed_closed_before_sell_semantic_registration`.

## Scope

Formal-v25 was an execution-only successor to formal-v24. It preserved the frozen 30-day panel, 3,516 opportunities, candidate ladder, folds, exact current-owner B0, repeated sequential-policy estimand, statistics, evidence boundaries, and false action/live permissions. It was intended to hash-rebind the 577 completed BUY cache units and restart only unfinished SELL work after the mmap lifetime repair.

## Failure

Formal-v25 passed its clean-tag identity gate, v24-to-v25 invariance gate, completed-BUY cache census, all-3,516 zero-economic C++ builder walk, first-opportunity eight-arm lockstep, full-day 648-arm lockstep, and formal mechanics preflight. At nested-run startup it hash-rebound the first completed BUY outer-train one-shot cache, then failed while registering that inherited cache as a semantic one-shot source because the successor manifest omitted the predecessor's top-level `semantic_day_input_sha256` evidence.

The inherited payload bytes and key invariants were intact; the defect was in successor evidence propagation. Exactly one successor BUY cache entry and one complete progress receipt were written, both as direct hash-verified inheritance. No BUY replay ran, SELL replay did not start, no formal result, nested OOF report, scorecard, candidate freeze, or promotion conclusion was produced, and no intermediate economic value was read or exposed.

## Preflight Accountability

This defect should have been caught before formal execution. The prior zero-economic checks verified the predecessor cache census and successor key rebinding but did not walk the actual inheritance-to-semantic-registration contract for every completed predecessor entry. A valid successor must preserve `semantic_day_input_sha256` for inherited one-shot entries and prove all 577 entries are contract-ready, including 67 one-shot semantic registrations, without parsing economic payloads.
