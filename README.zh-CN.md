## 研究公开范围与联系

NarrowGate 的具体研究内容、实验方案、生产策略实现、实效参数及结果不公开。本公开仓库仅包含最简 AS 教学示例、合成数据、通用教学回测规则和定性的基础研究方向。对研究或课题感兴趣、有疑问的朋友，欢迎通过邮件与我私下交流：[xuantan650@gmail.com](mailto:xuantan650@gmail.com)。

公开版仅包含教科书式 Avellaneda–Stoikov 报价示例、固定随机种子的虚构行情、透明的简化回测规则和定性的研究方向。它独立于完整私有程序，不是生产交易系统，也不是私有研究的复现版本。

## 本地运行

需要 Python 3.11 或更新版本，仅使用标准库。在仓库根目录执行：

```bash
python3 -m as_demo --seed 7 --events 200
python3 -m unittest discover -s tests -v
```

程序在内存生成虚构行情并打印教学账务摘要，不连接交易所、不下载数据、不读取凭据、不写入报告。所有数字示例均为教学构造，不来自真实市场拟合或生产实效配置。仓库不包含已记录的研究或交易收益。
