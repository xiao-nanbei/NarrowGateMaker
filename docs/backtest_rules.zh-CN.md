# 通用教学回测规则

[English](backtest_rules.md) | [简体中文](backtest_rules.zh-CN.md)

Last materially synchronized: 2026-10-28

以下是明确声明的教学假设，不是私有生产回测合同。

1. 事件时间必须有限、严格递增且位于指定期限内。非法方向、非正价格或成交量、空输入和非法配置均拒绝。同时间批次不受支持。
2. 每个事件先用该事件成交匹配此前已挂出的报价。主动卖单成交价不高于买价时，可成交买单；主动买单成交价不低于卖价时，可成交卖单。首个事件不能成交由自身产生的报价。
3. 按此前报价成交，不按观察到的成交价成交；数量取报价数量与事件成交量的较小值。每次成交事件最多匹配一侧。不模拟队列优先级，因此这种乐观规则不保证真实成交。
4. 应用成交和手续费，观察新的中间价，再使用更新后的库存撤换双边旧报价。事件间撤单和重挂瞬时完成，未成交残量不继承到下一对报价。新报价不会倒过来匹配产生它的事件。
5. 初始现金与库存均为零。对于带符号成交量 `dq`，更新 `inventory += dq` 与 `cash -= dq * price + fee`。手续费是非负的名义额费用，账务使用 Python 默认 Decimal 上下文下的十进制运算；教学实现不承诺无限精度。
6. 期末权益为 `cash + inventory * last_mid`。未平库存保留并按末价标记，不强制平仓；标记权益不是已实现利润。最后生成的报价没有后续事件可供成交。

合成价格是有下界的整数随机游走，主动方向和成交量为独立的虚构抽样。随机种子支持同一 Python 运行环境下复现，不使用真实数据或拟合分布。命令行将时间归一到单位期限。公式使用浮点计算，价格档位取整和现金账务使用 Decimal。

未模拟：队列深度、市场冲击、交易所价格带、价格改善、订单确认、网络延迟、融资、资金费、杠杆、保证金、强平、现金或库存限制、断线和生产防护。允许空头库存与负现金。示例不证明经济有效性或部署适用性。

测试覆盖因果顺序、主动方向、部分成交、取整、手续费、期末估值、确定性与非法输入。不能用此教学引擎替代经过验收的市场专用模拟器。
