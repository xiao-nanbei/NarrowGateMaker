# 基础研究方向

[English](research_directions.md) | [简体中文](research_directions.zh-CN.md)

Last materially synchronized: 2026-10-29

具体研究内容、实验方案、策略实现、实效参数及结果不公开。对研究或课题感兴趣、有疑问的朋友，欢迎通过邮件与我私下交流：[xuantan650@gmail.com](mailto:xuantan650@gmail.com)。

这里只给出定性的问题地图，不披露实现、调优数值、实验设计、排序或收益。教学示例没有实现这些研究族。

| 研究族 | 基础问题 |
| --- | --- |
| F01 — 参数稳健性 | 简单做市模型对固定参数选择有多敏感？ |
| F02 — 价格触及 | 报价距离与未来价格触及的机会有什么关系？ |
| F03 — 因果预测 | 预测能否只使用决策当时已经可用的信息？ |
| F04 — 外部市场信息 | 考虑信息可用性和时序后，相关市场能否提供额外信息？ |
| F05 — 成交质量 | 如何区分成交概率与成交之后的价格变化？ |
| F06 — 报价位置 | 价格位置与可见流动性如何关联成交机会？ |
| F07 — 挂单决策 | 何时保留已有报价比替换更合适？ |
| F08 — 执行选择 | 被动与主动执行在订单生命周期中有何差异？ |
| F09 — 库存生命周期 | 如何一致地评价开仓、持有与减仓？ |
| F10 — 回放对照 | 如何在明确假设下对比模拟行为与实际观察？ |

共性的工程问题包括可复现性、因果性和透明账务；不包含调度器或任务编排实现。这些问题不表示某个机制有效、已用于生产或能改善收益。回答它们需要独立的数据使用权、合适的基准和样本外验证。
