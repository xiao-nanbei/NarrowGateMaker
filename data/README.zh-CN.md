对外统一使用 `data`，负责获取、事实、观察与输入契约。用户按市场、频道、日期操作，不必选择供应商。交付地址和账户配置保持私有；内部适配器、清单仍记录真实来源，统一命名不等于抹去血缘。购买的行情记录不随源码发布。

## 代码目录

八个下载适配器统一放在 [downloaders/](downloaders/)：购买原件、Binance Vision、CryptoHFTData 盘口／成交、Bitget、Bybit、OKX，以及限额采样的 Infoway。Binance 和 CryptoHFTData 下载器保留，不删除。`pipeline.py legacy` 的显式历史命令指向该包；当前 `data download` 仍只走购买原件流程，不自动回退其他来源。内部适配器名称属于实现细节，不作为用户行情目录名称。解析／事实层、观察调度和质量检查放在下载目录之外；适配器内部已有的历史辅助逻辑，本次仅迁移目录，保持行为不变。

保留工具不等于其输出自动获得研究准入。本轮 F03 盘口／成交仍只用 Tardis，已有真实资金费作为独立授权的会计输入。具体对照由所选实验计划规定：本指南不取消已授权的 ML-OFF，也不恢复旧 B0。补充 metrics 不再是前置条件；已有 metrics 使用许可也不代表自动给新模型增加特征。本次整理本身不下载数据，也不代表模型兼容已经完成。

## 命令与存储

```bash
.venv/bin/python -m data --help
.venv/bin/python -m data download --config <private-delivery-config.json>
.venv/bin/python -m data inventory --root <purchased-archive-root> --output <private-calendar.json>
.venv/bin/python -m data normalize --plan <private-input-plan.json> --output <new-fact-bundle>
.venv/bin/python -m data validate --bundle <fact-bundle> --output <private-acceptance.json>
```

`narrowgate data ...` 和 `pipeline.py data ...` 调用同一实现。下载始终使用私有配置指定的可续传、仅原件路径，不隐式融合、删除来源或回退其他来源。202 保持等待并退避，其他到期文件继续处理，不算空文件或成功。压缩和已配置的内容检查通过后才完成。复用现有逐文件锁、任务锁和持久回执，包括已运行的任务。

购买的压缩原件保留在 **raw**，包括 `.incoming` 中的购买文件；按真实压缩识别 XZ、Zstandard。事实、观察、Bar、特征写入独立 **derived**。使用真实目录，不建供应商别名或软链接。临时工作可用其他磁盘，最终原子发布在目标文件系统内完成。私有交付配置和购买记录不得上传。

[dataset_scope.json](dataset_scope.json) 固定为 **407 个 UTC 日，2025-08-01～2026-09-11**：Binance USD-M 永续 BTCUSDC 执行市场、BTCUSDT 参考市场，各含 L2 与逐笔成交。上下文文件不增加分母，缺失、陈旧和困难日期仍保留。文件可用、内容验收、模型支持、历史使用权和经济准入分别判断。

## 事实与观察

[facts.py](facts.py) 通过共享精确解析器生成来源绑定的 Parquet 事实包。私有计划声明授权的 `source_profile`、有序 `files`、真实路径、symbol/channel、可选预期校验值及明确时钟证据，不接受旧混合 Parquet。所选完整输入集合共享磁盘成交身份索引，应包括必要相邻上下文；独立两个包不能声称已经跨包去重。

每个存储行是一条完整逻辑盘口消息或一笔去重成交，Parquet 行组不拆分快照。十进制值保持精确字符串。元数据绑定输入契约和原件校验值，读取器检查 schema、分片和来源身份。失败构建不发布有效包，已有包不覆盖。校验值证明字节身份，不证明经济正确性。

日常选择可把 `--plan` 换成 `--root <archive-root> --start YYYY-MM-DD --end YYYY-MM-DD --symbol BTCUSDC`，参考市场重复 `--symbol`，也可重复 `--channel`。所选区间每个必需日期都保留，不按来源排名或挑好日；缺文件或存在歧义时构建前明确失败。映射证据未知仍保持未知。`validate` 完整读取所选事实包并跨文件连续重建盘口；无效状态和源缺口保留为问题记录，不删除日期。

保留连续原始顺序及跨批次、片段的消息边界，不全局按时间排序或分组。供应商接收时间只用于技术分组与追踪，不作策略时间、本机接收或延迟校准。保留源时间含义和回退；映射无法证明时仍为 unknown，不自动成为精确交易所时间。统一单位不能补出时间证据。

快照原子替换已知书；增量设置绝对数量、零删除、同消息最后写入生效。整条消息先校验后修改。不可变 Top20/BBO 共享版本，维护全部已知深度；缺少覆盖证据时缺档为 unknown。重新快照不产生虚假撤单流、免费队列前移或本方撤单。真实新消息即使状态未变也可更新观察时间，但不更新状态变化时间；定时采样不刷新两者。

成交按市场/trade ID 精确比较经济内容：相同重复只算一次，内容冲突失败，同时间不同 ID 保留。个体成交数、原生包数和派生组数分开，缺失普通成交分类和原生聚合成员关系不伪造。

[observation.py](observation.py) 实现不可变观察、按接收顺序处理、显式派生深度发布器、ready 时间成交窗口及最小共享 `FeatureFrame`。历史记录和 live 聚合包通过明确适配器进入；ID 范围推导九笔时仍按观察到的包一次交付。严格历史适配器要求明确交易所时钟证据，拒绝未知或未来时钟；沿用盘口保留真实源观察时间。

发布时间、接收时间、ready 时间分开。窗口使用明确迟到截止规则，不倒写定时器实际处理时间；迟到贡献保留统计，不修改已关闭 Bar 或过去决策。观测为空时 OHLC 为空、观测量和计数为零，不等于证明交易所零成交；采集不明仍为 unknown。沿用估值价单列。参考市场未 ready 的信息不能进入特征帧。

这套最小特征契约**不是旧 13-head schema**，导入模块不会自动切换生产 signal 或正式回测。完整消费者迁移、情景声明和全日历验收仍需明确完成。

## 标签与经济准备

[contracts.py](contracts.py) 定义 203 个独立完整 48 小时账户和单列的最后 24 小时。各片从相同已声明资金、空仓、无挂单开始，市场和特征预热另算，片内午夜不重置。片末 MTM 不是免费清仓；账户重置前保留库存、估值身份与年龄、费用及有符号资金费。

标签资格按每个所需头的实际 outcome 终点严格剔除跨界样本，拒绝缺失或截尾结果，不生成标签。资金费或期末未实现损益未知时，全成本净收益保持空值。这些函数不替代正式成交/队列假设、执行账本和合法切分/使用清单。

## 实现边界

下表说明组件职责，不是正在运行的实验进度。实际完成情况须以所选实验的回执为准。

| 层级 | 已实现 | 仍需完成 |
| --- | --- | --- |
| 来源/解析 | 407 日清单、精确解析、磁盘去重、原子绑定事实包 | 所需购买文件、全日历扫描、历史时钟映射证据 |
| 盘口 | 原子更新、不可变已知深度 | 全日历缺口/回退/深度验收 |
| 观察/特征 | 交付、窗口、最小共享帧 | 完整新模型 schema、生产消费者迁移和端到端一致性 |
| 标签 | 实际终点资格 | 生成及合法切分/使用清单 |
| 经济 | 分片、MTM、缺资金费准备 | 具体实验的成交/队列/费用/资金费和账本集成 |
| 训练/回测/live | 数据工具不激活这些流程 | 独立的执行、验证及部署授权 |

单测使用合成 fixture；真实工程检查明确实际文件或窗口范围，不冒充全日历验收。未扫描的覆盖、年龄、去重和 future-fill 保持 unknown。事实层不填充的检查不能证明后续发布器通过。契约一致不等于原生包、接收时钟或真实队列一致。旧标签、模型、缓存不符合新契约。

## 历史工具与清理

日常操作统一使用 `data`。`pipeline.py legacy <command>` 明确属于历史工具，不是其他来源回退或当前准入。底层旧模块为历史机制和测试保留，可运行不代表获得新研究资格。

旧市场数据总说明已退役，原文可从保留的私有收敛快照恢复，不随公开仓库分发。其中混合来源布局、覆盖数量和好日筛选属于历史，不是当前默认值。Binance Vision 深度摘要不是增量 L2；Tardis L2 不提供本方原生订单队列身份。其他交易所、现货和桥接输入需要各自来源及可见性证据。资金费存储由[路径约定](../docs/path_conventions.zh-CN.md)定义，与盘口／成交分开。

仅清理确认过期、可再生且无运行任务占用的产物，同步更新当前引用。保留购买原件、资金费、历史使用权、锁定研究、独有 live/账户记录和历史机制文档。退役产物不等于整个研究思想无效。见[历史证据登记](../docs/legacy_l2_evidence_revalidation_20260725.md)和[路径/隐私约定](../docs/path_conventions.md)。
